## 🧩 About

**Sekiro overlay** is a curated list of Sekiro open-source tools:

- **Overlays** — on-screen helpers, layout notes, posture viewer, boss rush tracker
- **Quality-of-Life Helpers** — item catalog, skill planner, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- Posture Viewer — visualize posture buildup and break thresholds
- Boss Rush Tracker — track boss attempts and patterns
- Combat Arts Notes — review timing and inputs
- Playback Speed — adjust training playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse items, upgrades, and materials
- Skill Planner — organize skill tree progression
- Overlay Themes — customize HUD visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any boss
- Stealth Control — manually toggle stealth state for study
- Jump Buffer Notes — chain complex maneuvers in training
